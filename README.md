# Moon Calendar

Moon phase, a month calendar of phases and feast days, and a local barometer.

**Live demo:** https://kaiotei.github.io/1333-moon-calendar/

Built by [Kaiotei](https://github.com/Kaiotei) for [13 <33 Covenant](https://1333covenant.com) and released as one of its open-source apps.

## Features

- Phase, illumination and moon age computed locally (`moon-calc.js`), no API.
- Month grid with phases, the church year and feast days.
- Local weather: pressure, trend and sky from Open-Meteo, with place search.

## Run it

Open `index.html` through any static server (or GitHub Pages).

## Make it yours

`moon-calc.js` is standalone and reusable on its own.

**Stack:** Vanilla JS, Open-Meteo.
